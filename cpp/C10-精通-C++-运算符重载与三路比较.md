## 引言：六个比较运算符，要写几次？

```cpp
struct Version {
    int major, minor, patch;
};

// C++17 时代：想让 Version 可比较、可排序、可放进 set/map……
// 你需要手写几个运算符？
bool operator==(const Version&, const Version&);
bool operator!=(const Version&, const Version&);
bool operator< (const Version&, const Version&);
bool operator> (const Version&, const Version&);
bool operator<=(const Version&, const Version&);
bool operator>=(const Version&, const Version&);
// 六个！而且容易写错、不一致

// C++20 之后呢？
struct Version2 {
    int major, minor, patch;
    auto operator<=>(const Version2&) const = default;   // 就这一行？
};
```

答案：C++17 要手写**六个**比较运算符（且要保证彼此逻辑一致，极易出错）。**C++20 的三路比较 `<=>`（太空船运算符）** 让你写一行 `= default`，编译器就**自动合成全部六个**比较运算符，并按成员声明顺序做**字典序比较**。`Version2{1,2,3} < Version2{1,3,0}` 直接可用，还能丢进 `std::set`、用 `std::sort` 排序。

运算符重载让自定义类型用起来像内建类型（`a + b`、`v[i]`、`*p`）。但它规则繁多、陷阱不少。这一章讲清重载规则、成员 vs 非成员的选择、`explicit` 转换，以及 C++20 最省事的特性之一——`<=>` 如何消灭比较运算符的样板代码。

## 第一章：运算符重载的规则

运算符重载本质是**函数**，函数名为 `operator@`（`@` 是运算符）。

```cpp
struct Vec2 {
    double x, y;
    Vec2 operator+(const Vec2& o) const { return {x + o.x, y + o.y}; }  // 成员
};
Vec2 a{1,2}, b{3,4};
Vec2 c = a + b;        // 等价 a.operator+(b)  →  {4,6}
```

### 1.1 能与不能

**可以重载**：`+ - * / % ^ & | ~ ! = < > += -= ...`、`<< >>`、`++ --`、`[] () -> ->* new delete , ==` 等几十个。

**不能重载**（语言保留）：

| 运算符 | 为什么 |
|---|---|
| `.`（成员访问） | 保证类型系统一致 |
| `.*`（成员指针访问） | 同上 |
| `::`（作用域） | 编译期解析 |
| `?:`（三元） | 求值顺序语义无法保留 |
| `sizeof` / `alignof` / `typeid` | 编译期固有 |

### 1.2 不可违背的约束

- **不能发明新运算符**（如 `**`），不能改变**元数**（一元/二元）和**优先级/结合性**。
- 至少有一个操作数是**用户定义类型**（不能重载 `int + int`）。
- `=`、`[]`、`()`、`->` **必须是成员函数**。

### 1.3 保持直觉语义

重载应符合内建语义：`+` 不该有副作用、`==` 应自反对称、`operator<` 应是严格弱序（否则 `std::sort`/`std::map` 行为未定义）。**最小惊讶原则**——别让 `+` 干减法的事。

### 2.1 为什么对称运算符要用非成员

```cpp
struct Money {
    long cents;
    Money(long c) : cents(c) {}     // 允许 int 隐式转 Money
    // 成员版：左操作数必须是 Money
    Money operator+(const Money& o) const { return cents + o.cents; }
};
Money m{100};
auto a = m + 50;     // ✅ 50 隐式转 Money（右操作数）
// auto b = 50 + m;  // ❌ 50.operator+(m)? int 没有这个成员函数！
```

成员运算符的**左操作数不会隐式转换**（它是 `this`，类型固定）。要让 `50 + m` 也能用，把 `+` 写成**非成员**，左操作数才能参与隐式转换：

```cpp
Money operator+(const Money& a, const Money& b) { return a.cents + b.cents; }
auto b = 50 + m;     // ✅ 50 转 Money，两边对称
```

**经验法则**：对称的二元算术/比较运算符 → **非成员**（必要时声明为 `friend`）；修改自身的（`+=`、`++`）、`= [] () ->` → **成员**。

### 2.2 流运算符必须是非成员

```cpp
struct Point { int x, y; };
// 左操作数是 std::ostream（你改不了它），只能非成员
std::ostream& operator<<(std::ostream& os, const Point& p) {
    return os << '(' << p.x << ',' << p.y << ')';
}
std::cout << Point{1,2};   // ✅
```

`<<` 的左操作数是 `std::ostream&`（不属于你的类），无法作为成员，必须非成员（常声明为 `friend` 以访问私有成员）。

### 2.3 用 += 实现 +（DRY）

```cpp
struct Vec {
    double x, y;
    Vec& operator+=(const Vec& o) { x += o.x; y += o.y; return *this; }
};
// 用 += 实现非成员 +，避免重复逻辑
Vec operator+(Vec a, const Vec& b) { a += b; return a; }   // a 按值（接收一份副本来改）
```

## 第三章：特殊运算符

### 3.1 下标 []、调用 ()、解引用 ->

```cpp
struct Array {
    int data[10];
    int&       operator[](size_t i)       { return data[i]; }  // 可写
    const int& operator[](size_t i) const { return data[i]; }  // 只读
};

struct Adder {                       // 函数对象（functor）
    int base;
    int operator()(int x) const { return base + x; }  // 重载 ()
};
Adder add5{5};
int r = add5(10);                    // 15 —— 像函数一样调用

struct SmartPtr {
    Widget* p;
    Widget* operator->() const { return p; }    // -> 重载
    Widget& operator*()  const { return *p; }
};
```

`operator()` 让对象可"调用"——是 lambda、`std::function`、STL 谓词的基础（C20）。`operator[]` C++23 起支持**多参数**：`m[i, j]`。

### 3.2 递增/递减：前置 vs 后置

```cpp
struct Counter {
    int n = 0;
    Counter& operator++()    { ++n; return *this; }      // 前置：返回引用
    Counter  operator++(int) { Counter t = *this; ++n; return t; } // 后置：返回旧值副本
    //                  ^^^ 哑元 int 参数区分前置/后置
};
```

后置 `++` 有个**哑元 `int` 参数**（编译器用来区分），且要返回**自增前的副本**——所以后置通常比前置慢，循环里**优先用前置 `++it`**。

## 第四章：类型转换与 explicit

### 4.1 转换构造函数与转换运算符

```cpp
struct Fraction {
    int num, den;
    Fraction(int n) : num(n), den(1) {}      // 转换构造：int → Fraction
    operator double() const { return double(num) / den; }  // 转换运算符：Fraction → double
};
Fraction f = 5;          // 隐式转换（int → Fraction）
double d = f;            // 隐式转换（Fraction → double）
```

### 4.2 explicit —— 关掉危险的隐式转换

```cpp
struct Buffer {
    explicit Buffer(int size);    // explicit：禁止 int 隐式转 Buffer
};
// Buffer b = 100;    // ❌ 隐式转换被禁
Buffer b(100);        // ✅ 直接初始化
Buffer b2{100};       // ✅

void f(Buffer);
// f(100);            // ❌ 不会把 100 偷偷转成 Buffer
f(Buffer(100));       // ✅ 显式
```

**为什么要 explicit**：单参数构造函数会成为**隐式转换通道**，导致意外转换（如 `if (buffer)` 把对象转成别的、函数实参被悄悄转换）。**单参数构造函数默认应加 `explicit`**，除非你确实想要隐式转换（如 `std::string` 从 `const char*`）。

```cpp
explicit operator bool() const { return valid; }  // explicit 转换运算符
// 仅在"上下文需要 bool"时转换：if(obj)、while(obj) OK；但不会 int x = obj
```

> C++23 支持 `explicit(bool)`——条件性 explicit，按编译期条件决定是否显式。

## 第五章：三路比较 `<=>`（太空船运算符）

C++20 的杀手级简化。

### 5.1 一行生成全部比较

```cpp
#include <compare>
struct Version {
    int major, minor, patch;
    auto operator<=>(const Version&) const = default;  // 默认：按成员声明顺序字典序
    // == 也会被自动合成（C++20 规则）
};

Version a{1,2,0}, b{1,3,0};
bool lt = a < b;        // true —— < > <= >= 全部可用
bool eq = a == b;       // == != 也自动有
std::set<Version> s;    // 可直接做 set 的 key（需要 <）
```

`= default` 的 `<=>` 让编译器**按成员声明顺序逐个比较**（字典序），自动合成 `< > <= >= == !=` 全部六个。**省掉的样板**：从六个手写函数到一行。

### 5.2 三种比较类别

`<=>` 返回的不是 `bool`，而是一个**比较类别**对象，表示三种结果（小于/等于/大于）：

| 类别 | 含义 | 例子 |
|---|---|---|
| `std::strong_ordering` | 全序，且相等即可替换（`a==b` ⇒ 两者无差别） | `int`、字符串 |
| `std::weak_ordering` | 全序，但"相等"的元素可能有差异 | 大小写不敏感字符串（"ABC"=="abc" 但不同） |
| `std::partial_ordering` | 可能"无法比较" | `float`（NaN 与任何数都不可比） |

```cpp
std::strong_ordering   r1 = 1 <=> 2;        // less
std::partial_ordering  r2 = 1.0 <=> nan;    // unordered（无法比较）

// 用法：和 0 比较
if ((a <=> b) < 0)  { /* a < b */ }
if ((a <=> b) == 0) { /* a 等价 b */ }
```

### 5.3 自定义 `<=>`

```cpp
struct CaseInsensitive {
    std::string s;
    std::weak_ordering operator<=>(const CaseInsensitive& o) const {
        // 转小写后比较：'A' 和 'a' 等价但不相同 → weak_ordering
        std::string l1 = lower(s), l2 = lower(o.s);
        return l1 <=> l2;
    }
    bool operator==(const CaseInsensitive& o) const {     // == 通常要单独给
        return lower(s) == lower(o.s);
    }
};
```

⚠️ **要点**：当你**自定义**（非 default）`<=>` 时，`==` **不会**被自动合成——需要单独提供（出于性能，相等判断往往能短路，不必走完整三路比较）。只有 `= default` 的 `<=>` 才连带合成 `==`。

### 5.4 `<=>` 如何省掉样板——机制

编译器看到 `a < b`，若没有 `operator<`，会**改写（rewrite）** 为 `(a <=> b) < 0`；`a > b` 改写为 `(a <=> b) > 0`；`a != b` 改写为 `!(a == b)`。所以你只要提供 `<=>`（和 `==`），编译器就用这套**改写规则**合成其余所有关系运算符。这就是"一个运算符生成六个"的底层原理。

## 第六章：用户定义字面量

`operator""` 让你定义带后缀的字面量。

```cpp
struct Length { double meters; };

constexpr Length operator""_m(long double v)  { return {double(v)}; }
constexpr Length operator""_km(long double v) { return {double(v) * 1000}; }

auto d = 5.0_km;     // Length{5000}
auto h = 1.8_m;      // Length{1.8}
```

合法的字面量运算符参数有限：`(unsigned long long)`（整型）、`(long double)`（浮点）、`(const char*)`、`(const char*, size_t)`（字符串）等。标准库已用它实现 `std::chrono`（`10s`、`3h`）、`std::string`（`"abc"s`）、`std::complex`（`3i`）。

```cpp
using namespace std::chrono_literals;
auto timeout = 500ms;        // std::chrono::milliseconds
using namespace std::string_literals;
auto str = "hello"s;         // std::string（而非 const char*）
```

> 自定义后缀**建议以 `_` 开头**（如 `_km`）——无下划线的后缀保留给标准库。

## 第七章：常见陷阱清单

### ❌ 陷阱 1：成员运算符导致左操作数不能转换

```cpp
Money operator+(const Money&) const;   // 成员 → 50 + m 失败
```
对称二元运算符用**非成员**。

### ❌ 陷阱 2：单参数构造没加 explicit

```cpp
struct B { B(int); };
void f(B); f(42);     // 42 悄悄转成 B —— 意外！
```
单参构造默认加 `explicit`。

### ❌ 陷阱 3：自定义 `<=>` 后忘了写 `==`

```cpp
std::weak_ordering operator<=>(const T&) const;   // 没写 == → a == b 编译错误
```
非 default 的 `<=>` 不合成 `==`，要单独提供。

### ❌ 陷阱 4：浮点成员用 default `<=>` 期望 strong

```cpp
struct P { double x; auto operator<=>(const P&) const = default; };
// 推导出 partial_ordering（因 double 有 NaN）——放进 std::set 需注意
```

### ❌ 陷阱 5：循环里用后置 ++

```cpp
for (auto it = v.begin(); it != v.end(); it++)   // 后置：多一次拷贝
```
迭代器/对象优先 `++it`（前置）。

### ❌ 陷阱 6：重载运算符破坏直觉语义

```cpp
bool operator==(const T&) const { /* 还顺便修改了状态 */ }   // 惊吓！
```
`==` 应是 const、无副作用、对称。

### ❌ 陷阱 7：`operator<` 不满足严格弱序

```cpp
bool operator<(const T& o) const { return a <= o.a; }   // 用了 <= → 非严格弱序
// 放进 std::map/sort → 未定义行为
```

## 第八章：练习题

**练习 1**：为什么 `2 + obj` 要求 `+` 是非成员函数？

**练习 2**：哪些运算符**必须**是成员函数？哪些**不能**重载？

**练习 3**：单参数构造函数为什么通常要加 `explicit`？

**练习 4**：C++20 里 `auto operator<=>(const T&) const = default;` 会生成哪些运算符？`==` 在自定义 `<=>` 时会自动有吗？

**练习 5**：说出三种比较类别的区别，并各举一例：`int`、大小写不敏感字符串、`float`。

---

## 参考答案与解析

**练习 1**：成员运算符的左操作数是 `this`，**类型固定、不参与隐式转换**。`2 + obj` 需要把 `2` 当左操作数转成对象类型——只有非成员函数的两个参数才都能隐式转换，从而支持对称用法。

**练习 2**：**必须成员**：`= [] () ->`（以及 `->*`、`new`/`delete` 视情况）。**不能重载**：`.`、`.*`、`::`、`?:`、`sizeof`、`alignof`、`typeid`。

**练习 3**：单参数构造函数会成为**隐式转换通道**，使该类型对象在意料之外的地方被自动构造（函数实参、初始化、条件判断），引发难查的 bug。加 `explicit` 只允许显式构造，避免隐式转换；确需隐式转换（如 string 从字面量）才不加。

**练习 4**：`= default` 的 `<=>` 按成员声明顺序做字典序比较，**合成 `< > <= >= == !=` 全部六个**（编译器把关系比较改写为与 0 比较）。但**只有 default 的 `<=>` 才连带合成 `==`**；自定义（非 default）`<=>` 时，`==` 不自动生成，需单独提供。

**练习 5**：
- `std::strong_ordering`（`int`）：全序，相等即不可区分（可互相替换）。
- `std::weak_ordering`（大小写不敏感字符串）：全序，但"等价"的元素仍可能有差异（"ABC" 等价 "abc"，但内容不同）。
- `std::partial_ordering`（`float`）：可能不可比——`NaN <=> 1.0` 是 `unordered`。

## 小结

| 知识点 | 关键记忆 |
|---|---|
| 重载本质 | `operator@` 函数；不能造新运算符/改元数/改优先级 |
| 成员 vs 非成员 | 对称二元→非成员；`= [] () ->`→必须成员；`<<`→非成员 friend |
| 左操作数转换 | 成员的左操作数不转换 → `2+obj` 需非成员 |
| explicit | 单参构造默认加 explicit，防意外隐式转换 |
| `<=>` | 一行 `= default` 合成全部六个比较；按成员字典序 |
| 比较类别 | strong（int）/ weak（大小写无关）/ partial（float NaN） |
| `==` 合成 | 仅 default `<=>` 连带合成 ==；自定义需单独写 == |
| 字面量 | `operator""_x`，后缀以 `_` 开头；chrono/string 用它 |
| ++ | 前置返回引用、后置返回副本带哑元 int；循环用前置 |

## 📅 2026 现状/更新

- **三路比较 `<=>`（C++20）** 已被广泛采用，是消灭比较样板代码的标准做法；GCC 14 / Clang 18 / MSVC 19.4x 支持成熟。
- C++23 增强：**多参数 `operator[]`**（`mdspan[i,j]`，C32）、`explicit(bool)` 条件显式、`static operator()`/`static operator[]`（无状态函数对象更省）。
- 准则：**默认就用 `= default` 的 `<=>`**，除非有特殊比较语义；自定义时记得补 `==`；单参构造默认 `explicit`。
- 字面量与 `std::format`（C29）、`std::chrono` 配合让"带单位的值"表达更安全、可读。
