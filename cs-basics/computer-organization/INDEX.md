## 🗺️ 按模块组织

### 🟢 模块一：全局观（CO01）

> 先建立「一条指令是怎么被执行的」的完整心智模型，后面每章都是在给这个模型填细节。

- **CO01 系统概述与性能指标**：硬件 / 微指令 / 机器语言 / 汇编 / 高级语言的层次结构、冯·诺依曼五大部件与「存储程序」思想、取指-译码-执行的完整流程、**CPU 时钟周期 / 主频 / CPI / IPS / MIPS / FLOPS 的换算关系**（为什么高主频不等于快）、**Amdahl 定律**与并行加速上限

### 🔵 模块二：数据与运算（CO02-CO03）

> 这两章的计算题最"程式化"——套路固定、步骤明确，是最该拿满分的地方。

- **CO02 数据的表示与 IEEE 754**：任意进制互转、**原码 / 反码 / 补码 / 移码**的定义与转换（补码为什么能把减法变加法）、有符号/无符号溢出判断的三种方法、**IEEE 754 单双精度的位域划分**、隐含 1、偏置常数 127/1023、规格化数 / 非规格化数 / 无穷 / NaN 的编码、`0.1+0.2≠0.3` 的位级解释、大端小端、数据边界对齐
- **CO03 运算方法与运算器**：串行进位加法器的延迟瓶颈、**先行进位（超前进位）加法器**、`OF / SF / ZF / CF` 四个标志位的产生规则与**有符号无符号判断分歧**、原码一位乘 / **补码布斯（Booth）乘法**、恢复余数法与不恢复余数法（加减交替）除法、**浮点加减法四步**（对阶 → 尾数运算 → 规格化 → 舍入）与四种舍入方式

### 🟡 模块三：存储（CO04-CO05）

> CO05 是全科最难也最值钱的一章，Cache 地址划分几乎每年必考。

- **CO04 存储系统**：存储器层次金字塔（寄存器 → Cache → 主存 → 辅存）、存取时间 / 存取周期 / 带宽的区别、**SRAM vs DRAM**（为什么 DRAM 要刷新，集中 / 分散 / 异步三种刷新方式）、ROM 家族、**主存容量扩展**（位扩展 / 字扩展 / 字位同时扩展的芯片数计算与地址线分配）、双端口 RAM 与**多体交叉存储**（低位交叉的带宽计算）、**存储器的校验**（码距与检错纠错能力、**海明码校验位个数 `2^k ≥ n+k+1`** 与纠错定位、奇偶校验 / 海明码 / CRC 三者对比）、**磁盘阵列 RAID**（RAID 0/1/5/6/10 的容量、容错能力、写惩罚与适用场景）
- **CO05 Cache 与虚拟存储器**：程序访问的时空局部性、**直接映射 / 全相联 / 组相联三种映射方式的地址格式划分**（标记位 / 行号 / 块内地址各占几位——必考）、替换算法（LRU / FIFO / 随机）、**写直达 vs 写回**与写分配策略、命中率与**平均访问时间 AMAT** 计算、虚拟存储器（页式 / 段式 / 段页式）、**TLB / Cache / 主存三级查找的组合流程**、多级页表

### 🟠 模块四：指令与 CPU（CO06-CO07）

> 从"数据怎么存"过渡到"指令怎么跑"，流水线是大题常客。

- **CO06 指令系统**：指令格式（操作码 + 地址码）、定长 / 变长操作码、**扩展操作码的设计与地址空间计算**、零/一/二/三地址指令、**十种寻址方式**（立即 / 直接 / 间接 / 寄存器 / 寄存器间接 / 相对 / 基址 / 变址 / 堆栈 / 隐含）及各自的有效地址 EA 公式、**相对寻址的 PC 值陷阱**（PC 已经指向下一条）、CISC vs RISC 的六点对比、**程序的机器级代码表示**（AT&T vs Intel 语法、x86-64 寄存器组与参数传递约定、常用汇编指令、**选择与循环语句的机器级形态**、**过程调用的栈帧结构**与 `call`/`ret` 的动作、调用者/被调用者保存寄存器、递归的栈帧嵌套）
- **CO07 中央处理器**：CPU 功能与内部结构（运算器 + 控制器 + 寄存器组）、**指令周期 / 机器周期 / 时钟周期的包含关系**、单总线 / 专用通路数据通路与微操作序列、**硬布线控制器 vs 微程序控制器**（微指令格式：水平型 / 垂直型，微地址形成）、**五段流水线**（IF/ID/EX/MEM/WB）、三类冒险（结构 / 数据 / 控制）与解决手段（转发、阻塞、分支预测）、**流水线吞吐率 / 加速比 / 效率的计算公式**、超标量 / 超流水 / 多发射

### 🔴 模块五：互连与 I/O（CO08）

> 计算题（总线带宽、中断响应时间、DMA 传输周期）+ 概念题（三种 I/O 方式对比）。

- **CO08 总线与输入输出系统**：总线分类（片内 / 系统 / 通信）与三组信号线、**总线仲裁**（链式查询 / 计数器定时查询 / 独立请求）、**同步 / 异步 / 半同步定时**（异步的全互锁 / 半互锁 / 不互锁）、**总线带宽计算**、磁盘的物理结构与**平均存取时间**（寻道 + 旋转延迟 + 传输）、**三种 I/O 方式**：程序查询（CPU 全程等待）、**中断驱动**（中断响应过程、中断隐指令、多重中断与屏蔽字）、**DMA**（三种传送方式：停止 CPU、周期挪用、交替访问；DMA vs 中断的六点对比）

## 🎯 学习路径

### 路径 A：408 完整备考（6 周）

```
第 1 周  CO01 概述（建立全局观，性能指标公式要背熟）
第 2 周  CO02 数据表示（IEEE 754 必须能手工编解码）
第 3 周  CO03 运算方法（乘除法手算流程 + 标志位）
第 4 周  CO04 存储系统 + CO05 Cache（本科最重，慢啃）
第 5 周  CO06 指令系统 + CO07 CPU（流水线画时空图）
第 6 周  CO08 总线与 I/O（带宽 / 中断 / DMA 计算）
```

**本科特点**：概念题少、**计算题多**，且步骤高度模式化。备考策略是「**每类计算题各做 10 道，形成肌肉记忆**」，而不是反复读概念。

### 路径 B：后端工程师补硬件基础（2 周）

只挑对写代码有直接回报的：

- **CO02 IEEE 754** —— 理解浮点比较为什么不能用 `==`、金额为什么不能用 float
- **CO02 大小端与边界对齐** —— 网络字节序、struct 内存布局与填充
- **CO05 Cache** —— **cache line、伪共享、局部性优化**，直接决定并发与遍历性能
- **CO07 流水线与分支预测** —— 为什么排序后的数组遍历更快、分支预测失败的代价
- **CO08 DMA 与中断** —— 理解零拷贝、网卡收包、`iowait` 的来源

配合 [golang/G05 内存布局](../../golang/G05-精通-Go-Struct-内存布局与嵌入.md)、[golang/G20 内存管理](../../golang/G20-精通-Go-内存管理.md)、[linux/](../../linux/INDEX.md) 一起读。

### 路径 C：只突击计算题（1 周）

408 组成原理的计算题就这九类，各章对应位置：

| 题型 | 出处 | 核心公式 |
|---|---|---|
| CPI / MIPS / 执行时间 | CO01 | `执行时间 = 指令数 × CPI × 时钟周期` |
| Amdahl 加速比 | CO01 | `S = 1 / ((1-p) + p/k)` |
| 进制转换与补码 | CO02 | 补码 = 反码 + 1；`[-x]补 = ~[x]补 + 1` |
| IEEE 754 编解码 | CO02 | `(-1)^S × 1.M × 2^(E-127)` |
| 主存芯片扩展 | CO04 | `芯片数 = 总容量 / 单片容量`（分位、字两个方向） |
| **海明码校验位数** | CO04 | `2^k ≥ n + k + 1`；纠 t 位需码距 `≥ 2t+1` |
| RAID 容量与容错 | CO04 | RAID 5：容量 `n−1`，容错 1 块；RAID 6：容量 `n−2`，容错 2 块 |
| **Cache 地址划分** | CO05 | 标记 + 行号/组号 + 块内地址 = 物理地址位数 |
| 平均访问时间 AMAT | CO05 | `AMAT = 命中时间 + 缺失率 × 缺失代价` |
| **流水线加速比** | CO07 | `S = T不流水 / T流水`；`T流水 = (k + n - 1) × Δt` |
| 总线带宽 / DMA | CO08 | `带宽 = 数据线位数 × 频率 / 8`（B/s） |
| **栈帧与参数传递** | CO06 | 参数 `rdi/rsi/rdx/rcx/r8/r9`，返回值 `rax`；`call` = 压返回地址 + 跳转 |
