## 🗺️ 按模块组织

### 🟢 模块一：地基（DS01）

> 复杂度不是"看一眼循环层数"，而是能推导、能证明、能反例。

- **DS01 绪论与复杂度分析**：逻辑结构 / 存储结构 / 数据运算三个层次、大 O / Ω / Θ 的严格定义（为什么 O 是"上界"而非"精确"）、非递归程序的求和法、递归程序的递归树与**主定理**、最好 / 最坏 / 平均 / **摊还**四种分析（动态数组扩容的摊还 O(1) 怎么算出来的）

### 🔵 模块二：线性结构（DS02-DS04）

> 408 大题里线性表出得最多，因为它最能考"边界处理"。

- **DS02 线性表**：顺序表的插入删除移动次数期望（`n/2` 与 `(n-1)/2` 怎么来的）、单链表带不带头结点的写法差异、双链表 / 循环链表 / **静态链表**（考纲要求但工程罕见）、链表三大套路（快慢指针、原地反转、归并）
- **DS03 栈、队列与数组**：顺序栈的两种栈顶指针约定、共享栈判满、**循环队列三种判满方案**（牺牲一格 / 计数器 / tag 标志，考了二十年）、栈与递归的等价、单调栈、对称矩阵 / 三角矩阵 / 三对角矩阵 / 稀疏矩阵的**下标映射公式**
- **DS04 串与 KMP**：定长顺序串 / 堆分配串 / 块链串、BF 算法退化到 O(nm) 的具体输入、**next 数组的两种定义**（从 0 开始 vs 从 1 开始，408 用后者）、手推 next 的表格法、nextval 优化的动机与推导

### 🟡 模块三：非线性结构（DS05-DS06）

> 树和图是拉开分数的地方，大题几乎必考其一。

- **DS05 树与二叉树**：五大性质（`n0 = n2 + 1` 的证明）、完全二叉树的下标关系、前 / 中 / 后 / 层序遍历的递归与**非递归实现**、"哪两种遍历序列能唯一确定二叉树"、线索二叉树的前驱后继查找、树 / 森林 ↔ 二叉树转换（孩子兄弟表示法）、哈夫曼树与 WPL、**并查集**路径压缩与按秩合并
- **DS06 图**：邻接矩阵 vs 邻接表的空间与操作复杂度、DFS / BFS 生成树、**Prim vs Kruskal** 选型（稠密图 vs 稀疏图）、Dijkstra 为什么不能处理负权边（反例）、Floyd 三重循环的 k 为什么必须在最外层、拓扑排序判环、AOE 网关键路径与关键活动

### 🟠 模块四：查找与排序（DS07-DS08）

> 两章合起来是分值密度最高的部分，也是工程回报最直接的部分。

- **DS07 查找**：ASL 的成功 / 失败两种算法、**折半查找判定树**（失败结点怎么画）、分块查找、BST 的删除三种情形、**AVL 四种旋转**（LL / RR / LR / RL）与最少结点数递推、红黑树五条性质与插入调整、**B 树的分裂与合并**、B+ 树为什么更适合数据库索引、散列表的冲突处理（拉链 / 线性探测 / 平方探测）与**装填因子**对 ASL 的影响
- **DS08 排序**：八大内部排序的时间 / 空间 / 稳定性全对照、直接插入 vs 折半插入的比较次数、**希尔排序增量序列**、快排的枢轴选择与最坏退化、**堆的建堆复杂度为什么是 O(n)**、归并的分治与稳定性、基数排序的 LSD 流程、外部排序的归并趟数、**败者树**与置换-选择排序、最佳归并树

## 🎯 学习路径

### 路径 A：408 完整备考（8 周）

```
第 1 周  DS01 复杂度（打地基，别跳）
第 2-3 周 DS02 线性表 + DS03 栈队列数组（大题高频）
第 4 周  DS04 串与 KMP（next 数组必须手推熟练）
第 5-6 周 DS05 树 + DS06 图（分值最重，慢慢啃）
第 7 周  DS07 查找（AVL / B 树画图题）
第 8 周  DS08 排序（背表 + 手推每趟结果）
```

每章配套：**先手推**（纸上画图/列表），**再敲代码**（Go 实现验证），**最后刷力扣题单**。
