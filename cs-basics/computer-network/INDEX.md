## 🗺️ 按模块组织

### 🟢 模块一：地基（CN01）

> 先建立「一个字节从这台机器到那台机器要穿过几层、每层加了什么头」的心智模型，后面五章都是在给某一层填细节。

- **CN01 体系结构与性能指标**：网络的组成与分类、**三种交换方式**（电路交换 / 报文交换 / 分组交换的时延对比与适用场景）、分层的动机、**实体 / 协议 / 服务 / 服务访问点**四个核心概念的辨析、OSI 七层 vs TCP/IP 四层 vs **五层教学模型**、各层 PDU 名称与典型设备、**封装与解封装的完整过程**、速率 / 带宽 / 吞吐量三者区别、**四种时延**（发送 / 传播 / 处理 / 排队）的公式与辨析、**时延带宽积**（"以比特为单位的链路长度"）、RTT、信道利用率

### 🔵 模块二：底层两层（CN02-CN03）

> 计算题密度最高的两章：CRC、海明码、信道极限、最小帧长、退避时间、CDMA 内积，全是**给数字就能算**的送分题。

- **CN02 物理层与数据链路层**：数据 / 信号 / 码元的关系、**波特率 vs 比特率**（`比特率 = 波特率 × log₂V`）、**奈奎斯特定理**（无噪声）与**香农定理**（有噪声）的公式、适用条件与**取小者**原则、编码（NRZ / 曼彻斯特 / 差分曼彻斯特）与调制（ASK/FSK/PSK/QAM）、封装成帧与**四种透明传输方法**、差错控制三级：奇偶校验 → **CRC 循环冗余码**（模 2 除法手算）→ **海明码**（校验位个数 `2^k ≥ n+k+1`、纠一位错的定位）、**停止-等待 / 后退 N 帧 GBN / 选择重传 SR** 三协议的窗口约束与信道利用率
- **CN03 局域网与介质访问控制**：IEEE 802 体系与 LLC/MAC 分层、**三大类介质访问控制**（信道划分 / 随机访问 / 轮询访问）、四种复用（FDM/TDM/WDM/CDM）、**CDMA 码片序列与内积规则**（规格化内积 = 1 / −1 / 0）、ALOHA → CSMA → **CSMA/CD**（争用期 `2τ`、**最小帧长 = 总线传播时延 ×2× 数据率**、二进制指数退避）、**CSMA/CA**（为什么无线不能用 CD）、令牌传递、**以太网 MAC 帧格式**与 MAC 地址、**冲突域与广播域的划分**（集线器 / 网桥 / 交换机 / 路由器各隔离什么）、**交换机自学习与转发表**、VLAN 三种划分方式

### 🟡 模块三：网络层（CN04）

> 全科最难也最值钱的一章。**子网划分 + 最长前缀匹配 + 路由表计算**是大题的主要来源。

- **CN04 网络层**：网络层的功能与**面向连接 vs 无连接**（虚电路 vs 数据报）、**IPv4 首部 13 个字段**、分类编址（A/B/C 类的范围与私有地址段）、**子网划分与子网掩码**（借位、可用主机数 `2ⁿ - 2`）、**CIDR 与路由聚合**、**最长前缀匹配**的查表规则、**IP 分片**（片偏移以 8 字节为单位、MF/DF 标志、完整分片计算）、**ARP**（同网段直接解析、跨网段解析网关 MAC）、DHCP 的四步租约、**ICMP**（五种差错报文 + 两种询问报文，ping 与 traceroute 原理）、**NAT 与 NAPT**、**RIP**（距离向量、`最大 15 跳`、坏消息传得慢与三种缓解手段）、**OSPF**（链路状态、Dijkstra、五种分组、区域划分）、RIP vs OSPF 全面对比、BGP（路径向量、AS 间）、IPv6 的改进与过渡技术、**路由器的组成**（控制平面 vs 数据平面、输入端口 / **交换结构的三种实现** / 输出端口、路由表 vs 转发表）、**IP 组播**（D 类地址、**IGMP 与组播路由协议的分工**、只发一份在分叉点复制）、**移动 IP**（归属地址 / 转交地址 COA / 归属代理 / 外部代理、**IP-in-IP 隧道**、**三角路由**问题）、**SDN**（控制与转发分离、控制器的全局视图、南向 **OpenFlow** 与**流表三要素**）

### 🟠 模块四：传输层（CN05）

> 与网络层并列的高频大题章。**三次握手 / 四次挥手 / 拥塞窗口演化**几乎年年考。

- **CN05 传输层**：传输层的两个核心职责（**端到端**通信 + 复用分用）、端口号分类与常见端口、**UDP 首部 8 字节**与**伪首部**（参与校验但不发送，且校验和可选）、UDP 适用场景、**TCP 首部各字段**（序号 / 确认号 / 数据偏移 / 六个标志位 / 窗口 / 紧急指针）、**三次握手**（为什么不是两次——历史连接与资源浪费；SYN 洪泛与 SYN Cookie）、**四次挥手**（为什么比握手多一次；**TIME_WAIT 为什么等 2MSL**）、**TCP 状态机**、可靠传输三机制（校验 / 序号确认 / 超时重传）、**RTO 的自适应计算**（加权 RTT + Karn 算法）、**快速重传**（三个重复 ACK）、**流量控制**（滑动窗口、零窗口探测与死锁）、**拥塞控制四算法**（慢开始 / 拥塞避免 / 快重传 / 快恢复）与 **cwnd 演化曲线**、流量控制 vs 拥塞控制的辨析

### 🔴 模块五：应用层（CN06）

> 概念为主、计算少，但**"打开一个网页发生了什么"**是把六章串起来的最佳复习题。

- **CN06 应用层**：C/S 与 P2P 模型、**DNS**（域名层次、四类域名服务器、**递归查询 vs 迭代查询**的完整报文流、DNS 缓存与 TTL、A/AAAA/CNAME/MX/NS 记录）、**FTP**（**控制连接 21 + 数据连接 20**、**主动 PORT vs 被动 PASV**、为什么防火墙下要用被动）、电子邮件三协议分工（**SMTP 发信推、POP3/IMAP 收信拉**）、POP3 vs IMAP、MIME、**HTTP**（请求/响应报文格式、方法、**状态码五类**、无状态与 Cookie/Session、**非持久 vs 持久连接的 RTT 计算**、流水线）、HTTP 版本演进（1.0 → 1.1 → 2 多路复用 → 3 QUIC）

## 🎯 学习路径

### 路径 A：408 完整备考（3 周）

```
第 1 周  CN01 体系结构（时延公式必背）+ CN02 物理与链路层（CRC / 海明码各算 10 遍）
第 2 周  CN03 局域网（最小帧长）+ CN04 网络层（子网划分是重中之重）
第 3 周  CN05 传输层（握手挥手 + 拥塞窗口）+ CN06 应用层（概念速过）
```

**本科特点**：**最好拿分的一科**。协议细节明确、计算题套路固定、几乎没有"理解性难点"。备考策略是「**把六类计算题各刷 10 道 + 把陷阱清单背熟**」，25 分应当当作**满分目标**而不是及格目标。

### 路径 B：后端工程师补网络基础（1 周）

只挑对排障有直接回报的：

- **CN01 四种时延与时延带宽积** —— 理解为什么"带宽升级了但延迟没变"、长肥管道为什么要调窗口
- **CN04 子网划分与 NAT** —— 看懂 K8s 的 Pod CIDR、Service ClusterIP、容器网络冲突
- **CN05 三次握手 / TIME_WAIT / 拥塞控制** —— **线上排障最高频的理论**（`CLOSE_WAIT` 堆积 = 应用没 close；`TIME_WAIT` 堆积 = 主动关闭方太多）
- **CN06 DNS 与 HTTP 连接管理** —— 解析超时、连接池大小、Keep-Alive 与队头阻塞

工程视角对照 [backend/B01 互联网工作原理](../../backend/B01-精通互联网工作原理.md)、[backend/B02 HTTP 语义](../../backend/B02-精通-HTTP-语义.md)、[linux/](../../linux/INDEX.md) 协议栈实现。

### 路径 C：只突击计算题（3 天）

408 计算机网络的计算题就这九类，各章对应位置：

| 题型 | 出处 | 核心公式 |
|---|---|---|
| 四种时延与总时延 | CN01 | `发送时延 = 数据长度 / 带宽`；`传播时延 = 距离 / 速度`（**与带宽无关**） |
| **时延带宽积** | CN01 | `时延带宽积 = 带宽 × 单向传播时延`（单位 bit） |
| 信道极限速率 | CN02 | 奈氏 `C = 2W·log₂V`；香农 `C = W·log₂(1 + S/N)`，**两者取小** |
| **CRC 余数** | CN02 | 模 2 除法，补 `r` 个 0（`r` = 生成多项式最高次） |
| 海明码校验位数 | CN02 | `2^k ≥ n + k + 1` |
| **最小帧长** | CN03 | `最小帧长 = 2τ × 数据率`（τ = 单程传播时延） |
| **子网划分** | CN04 | 借 `n` 位 → `2ⁿ` 个子网，每个 `2^(32-前缀) - 2` 台主机 |
| IP 分片 | CN04 | 片偏移 = 前面所有片的**数据字节数 / 8**，每片数据须为 **8 的倍数** |
| **拥塞窗口演化** | CN05 | 超时：`ssthresh = cwnd/2, cwnd = 1`；三重 ACK：`ssthresh = cwnd/2, cwnd = ssthresh`（快恢复） |
