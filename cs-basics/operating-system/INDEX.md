## 🗺️ 按模块组织

### 🟢 模块一：地基（OS01）

> 操作系统到底"运行"在什么位置上——这一章回答的是这个问题。

- **OS01 概述与运行环境**：操作系统的四大特征（**并发**与并行的区别、共享的两种形式、虚拟的四种技术、异步性）、发展历程（批处理 → 分时 → 实时）、**内核态与用户态的切换机制**、特权指令、**中断与异常的分类**（内中断 / 外中断、故障 / 陷阱 / 终止）、**系统调用的完整流程**（为什么必须经陷入指令而不能直接跳转）、大内核 vs 微内核

### 🔵 模块二：进程管理（OS02-OS05）

> 408 操作系统的**主战场**，35 分里有 20 分左右出自这四章。

- **OS02 进程与线程**：进程的定义与特征、**PCB 的内容与作用**、进程实体 = 程序段 + 数据段 + PCB、**五状态模型的七种转换**（哪些转换不可能发生是必考点）、进程控制原语的原子性、**IPC 三种方式**（共享存储、消息传递、管道）与各自的同步要求、线程的引入动机、**用户级线程 vs 内核级线程**（多对一 / 一对一 / 多对多模型的优缺点）
- **OS03 CPU 调度**：高级 / 中级 / 低级三级调度、**周转时间 / 带权周转时间 / 等待时间 / 响应时间**的定义与计算、六种算法（FCFS、SJF/SRTN、HRRN、RR、优先级、**多级反馈队列**）的手算、**时间片大小对 RR 的影响**、饥饿问题、调度时机与切换开销
- **OS04 同步与互斥**：临界区问题的**四个原则**（空闲让进 / 忙则等待 / 有限等待 / 让权等待）、软件方案（单标志、双标志先检查/后检查、**Peterson**）各自违反哪条原则、硬件方案（中断屏蔽、TSL/Swap）、**信号量 P/V 操作**、用信号量解决**五大经典问题**（生产者-消费者、多生产者多消费者、读者-写者、哲学家进餐、吸烟者）、**管程**与条件变量
- **OS05 死锁**：死锁的四个必要条件、死锁 vs 饥饿 vs 死循环、三种处理策略、**死锁预防**（破坏四条件各自的代价）、**死锁避免与银行家算法**（安全序列的完整求解步骤）、**死锁检测**（资源分配图化简）与解除

### 🟡 模块三：内存管理（OS06-OS07）

> 计算题最集中的两章，地址变换和页面置换几乎年年考。

- **OS06 内存管理**：绝对装入 / 静态重定位 / **动态重定位**、连续分配（单一连续、固定分区、**动态分区**）、**四种动态分区算法**（首次适应 / 最佳适应 / 最坏适应 / 邻近适应）的手算与优劣、**内部碎片 vs 外部碎片**（最高频概念题）、**基本分页**（页表、地址变换过程、快表 TLB、**两级页表**的引入动机与地址划分）、基本分段与段表、**分页 vs 分段的五点区别**、段页式的三次访存
- **OS07 虚拟内存**：局部性原理与虚拟内存的三大特征、请求分页的页表项（状态位 / 访问字段 / 修改位 / 外存地址）、**缺页中断的完整处理流程**（属于内中断的哪一类）、**四种页面置换算法手算**（OPT / FIFO / LRU / CLOCK 与改进型 CLOCK）、**Belady 异常**（为什么只有 FIFO 有）、页面分配策略（固定 / 可变 × 局部 / 全局）、**抖动与工作集**、内存映射文件 mmap

### 🟠 模块四：文件与 I/O（OS08-OS09）

> 概念题为主，但混合索引寻址和磁盘调度是稳定的计算题来源。

- **OS08 文件管理**：文件的属性与操作、逻辑结构（顺序 / 索引 / 索引顺序 / 散列）、目录结构演进（单级 → 两级 → 树形 → **无环图**）与 FCB、**三种物理分配方式**（连续 / 链接（隐式 + 显式 FAT）/ 索引）的优缺点与随机访问能力、**UNIX 混合索引**（直接块 + 一级/二级/三级间址的最大文件大小计算）、**硬链接 vs 软链接**、空闲空间管理（空闲表 / 空闲链 / **位示图** / 成组链接）
- **OS09 磁盘与 I/O 管理**：磁盘物理结构与**磁盘地址（柱面号 + 盘面号 + 扇区号）的排列顺序**、**平均存取时间三段式**、**四种磁盘调度算法手算**（FCFS / SSTF / SCAN / C-SCAN，及 LOOK / C-LOOK）、减少延迟的**交替编号与错位命名**、磁盘格式化与分区、I/O 控制的四种方式、**I/O 软件的四个层次**、**四种缓冲区**（单缓冲 / 双缓冲 / 循环缓冲 / 缓冲池）的时间计算、设备分配与 **SPOOLing 假脱机**

## 🎯 学习路径

### 路径 A：408 完整备考（5 周）

```
第 1 周  OS01 概述（概念多但简单，快速过）
第 2 周  OS02 进程线程 + OS03 调度（调度算法手算要熟）
第 3 周  OS04 同步互斥 + OS05 死锁（PV 操作 + 银行家，最难两章）
第 4 周  OS06 内存 + OS07 虚拟内存（地址变换 + 置换算法）
第 5 周  OS08 文件 + OS09 磁盘（混合索引 + 磁盘调度）
```

**本科特点**：**概念辨析题多**（如"下列哪个转换不可能发生"），需要精确记忆；**大题集中在** PV 操作、银行家算法、页面置换、磁盘调度四处。

### 路径 B：后端工程师补 OS 基础（2 周）

- **OS02** 进程 vs 线程、IPC —— 理解容器、进程模型
- **OS04** 信号量与管程 —— **所有并发原语的祖先**，`sync.Mutex`/`WaitGroup`/`Cond` 都能在这找到源头
- **OS05** 死锁四条件 —— 线上死锁排查的理论基础
- **OS07** LRU / CLOCK —— **缓存淘汰策略的源头**（Redis 的近似 LRU、LFU 就是这些算法的工程变体）
- **OS09** 缓冲与 I/O 控制 —— 理解 page cache、零拷贝

工程实现对照 [linux/](../../linux/INDEX.md)（内核视角）、[golang/](../../golang/INDEX.md)（runtime 视角）。

### 路径 C：只突击大题（1 周）

408 操作系统的大题就这五类：

| 题型 | 出处 | 关键步骤 |
|---|---|---|
| **调度算法计算** | OS03 | 画甘特图 → 算完成时间 → 周转 = 完成 - 到达 → 带权周转 = 周转/运行 |
| **PV 操作设计** | OS04 | 先定同步关系 → 每个关系设一个信号量 → **互斥 P 在同步 P 之后** |
| **银行家算法** | OS05 | 算 Need → 找能满足的进程 → 假设回收 → 循环 → 输出安全序列 |
| **地址变换 / 页面置换** | OS06-07 | 分页：页号 = 逻辑地址 / 页大小；置换：画访问表逐列填 |
| **磁盘调度** | OS09 | 画磁道移动路径 → 累加移动距离 → 算平均寻道长度 |
