# 算法面试深度课程 · 总目录

> 面向后端工程师**编码面试（Coding Interview）**的算法专题，共 **20 篇**深度长文。
> 不是题海，而是**按题型组织的"解题模板 + 思维框架"**：每篇讲清"这类题怎么识别、套什么模板、复杂度多少、边界与陷阱在哪"，配套精选例题讲透思路。
>
> **📅 内容基准：2026 年 6 月。** 代码示例用 **Go**（贴合本项目主语言，见 [Go 专题](../golang/INDEX.md)）；思路与模板语言无关。
>
> **定位**：本专题讲"算法思维与题型模板"，**不替代 OJ 刷题**——刷题去 LeetCode，本专题帮你**建立解题套路、面试时讲清思路**。是 OfferPilot 评测「算法」维度的内容底座。

## 🗺️ 按模块组织

### 🟢 模块一：基础与方法论（01-03）

> 算法面试不只考"会不会写"，更考"怎么想、怎么说、怎么优化"。先打好复杂度和基础数据结构的底子。

- **01 复杂度与方法论**：大 O / 均摊分析；**面试解题四步法**（澄清→举例→思路与复杂度→编码与测试）；如何从暴力解优化
- **02 数组与字符串**：前缀和、差分、原地双指针、区间问题
- **03 链表**：哑结点（dummy）、反转、快慢指针、环检测——链表题的固定套路

### 🔵 模块二：核心题型模板（04-09）

> 面试 70% 的题都能归到这几类模板。识别题型 → 套模板 → 调边界。

- **04 双指针**：对撞指针、快慢指针、同向双指针；三数之和、盛水容器
- **05 滑动窗口**：可变长 + 定长窗口通用模板；最长/最短子串、子数组
- **06 二分查找**：**边界处理是核心**；旋转数组、二分答案（把求解转成判定）
- **07 排序算法**：快排/归并/堆排原理与手写、计数/桶/基数、稳定性、面试考点
- **08 递归回溯 DFS**：**回溯通用模板**；子集/排列/组合、剪枝、N 皇后、岛屿
- **09 分治**：分治框架、归并应用（逆序对）、主定理

### 🟡 模块三：栈队列与树图（10-14）

> 数据结构驱动的题型，二叉树和图是绝对高频。

- **10 栈与队列**：单调栈（下一个更大元素）、单调队列（滑窗最值）、括号匹配、表达式求值
- **11 哈希表与设计题**：哈希加速、LRU（哈希+双链表）、LFU、设计类题套路
- **12 二叉树**：前中后序 + 层序遍历、**递归解题套路（自顶向下/自底向上）**、BST、最近公共祖先
- **13 堆与 Top K**：优先队列、Top K 三种解法、第 K 大、数据流中位数
- **14 图论**：建图、BFS/DFS、拓扑排序、并查集、最短路（Dijkstra/BFS）

### 🟣 模块四：动态规划与贪心（15-17）

> DP 是面试"分水岭"，也是最让人头疼的。本模块给出可复用的思维框架。

- **15 动态规划基础**：**状态定义 → 转移方程 → 初始化 → 遍历顺序**四步法；记忆化搜索；滚动数组优化
- **16 经典 DP 专题**：背包（01/完全/多重）、子序列（LIS/LCS）、编辑距离、区间 DP、树形 DP、状压 DP
- **17 贪心**：贪心的"无后效性"、如何证明/反例、区间调度、跳跃游戏、贪心 vs DP

### 🟠 模块五：高频进阶与总结（18-20）

- **18 字符串高级**：KMP（next 数组）、Trie 字典树、Manacher（最长回文）、字符串哈希
- **19 位运算与数学**：位运算技巧（异或/lowbit）、快速幂、GCD、质数筛、常见数学题
- **20 总结**：题型速查表、模板汇总、**刷题路线图**、面试高频题清单、临场策略

## 🎯 学习路径建议

### 路径 A：面试突击（3-4 周）

```
01 方法论 + 复杂度（先会分析、会沟通）
   ↓
04 双指针 + 05 滑动窗口 + 06 二分（高频模板）
   ↓
08 回溯 + 12 二叉树 + 13 堆（高频结构）
   ↓
15 DP 基础 + 16 经典 DP（攻克难点）
   ↓
20 高频题清单查漏补缺
```

### 路径 B：系统打基础（2-3 个月）

```
按 01→20 顺序，每篇：读模板 → 做 3-5 道对应 LeetCode 题 → 回头对照模板
```

### 路径 C：DP 专项突破（2 周）

```
15 DP 基础（建立框架）→ 16 经典 DP（逐类型攻克）→ 17 贪心（对比）
```

## ✅ 完读检查清单

读完整个系列后，应该能：

- [ ] 准确分析任意代码的时间/空间复杂度，解释均摊复杂度
- [ ] 看到题就能识别它属于哪类题型、该套哪个模板
- [ ] 手写快排、归并、堆排，说清稳定性和适用场景
- [ ] 默写双指针、滑动窗口、二分、回溯、BFS/DFS 的通用模板
- [ ] 用"状态定义→转移方程→初始化→遍历顺序"四步法推导 DP
- [ ] 区分贪心和 DP，能对贪心策略举反例或简单证明
- [ ] 实现并应用并查集、单调栈、Trie、优先队列
- [ ] 面试时按"澄清→暴力→优化→编码→复杂度"五步讲清思路
