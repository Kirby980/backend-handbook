# 精通位运算与数学

> 位运算和数学题在面试中是"小而精"的考点——异或找只出现一次的数、快速幂、GCD、质数筛、状态压缩。它们往往有巧妙的 O(1)/O(log n) 解法。本篇梳理高频的位运算技巧和数学算法。
>
> **📅 基准：2026 年 6 月。** 代码用 Go。

---

## 一、位运算基础

| 运算 | 符号 | 作用 |
|---|---|---|
| 与 | `&` | 都为 1 才 1（清零、取位） |
| 或 | `\|` | 有 1 则 1（置位） |
| 异或 | `^` | 不同为 1、相同为 0（翻转、找不同） |
| 取反 | `^x`（Go 一元） | 0↔1（Go 用 `^x`，不是 `~`） |
| 左移 | `<<` | 乘 2ⁿ |
| 右移 | `>>` | 除 2ⁿ |

```go
x & 1        // 取最低位（判奇偶：==1 奇，==0 偶）
x >> 1       // 除以 2
x << n       // 乘以 2ⁿ
x & (x - 1)  // 消去最低位的 1（高频技巧）
x & (-x)     // 取最低位的 1（lowbit，树状数组用）
```

位运算直接操作二进制位，**快**（CPU 单指令）。注意 Go 取反是 `^x`（一元 `^`）、没有 `~`。

## 二、常用位运算技巧

```go
// 判奇偶：看最低位
isOdd := x & 1 == 1

// 交换两数（不用临时变量，异或）
a ^= b; b ^= a; a ^= b

// 统计二进制中 1 的个数（Brian Kernighan 算法）
func countOnes(x int) int {
    count := 0
    for x != 0 {
        x &= x - 1 // 每次消去最低位的 1
        count++
    }
    return count
}

// 判断是否 2 的幂：只有一个 1
func isPowerOfTwo(x int) bool {
    return x > 0 && x&(x-1) == 0
}
```

核心技巧：
- **`x & (x-1)`**：消去最低位的 1——用于统计 1 的个数、判 2 的幂。
- **`x & (-x)`**：取最低位的 1（lowbit）——树状数组、状态枚举。
- **`x & 1`**：取最低位（判奇偶）。
- **`x >> i & 1`**：取第 i 位。

记住这几个，位运算题大半能解。

## 三、异或的妙用

**异或（^）** 性质独特，是位运算题的明星：
- `a ^ a = 0`（自己异或自己为 0）。
- `a ^ 0 = a`（和 0 异或不变）。
- 满足交换律、结合律。

由此推出经典应用：

```go
// 只出现一次的数字：其余都出现两次，全部异或，成对的抵消，剩下唯一的
func singleNumber(nums []int) int {
    res := 0
    for _, x := range nums {
        res ^= x // 出现两次的异或为 0，最后剩出现一次的
    }
    return res
}
```

为什么对：所有数异或，出现两次的 `a^a=0` 互相抵消，最后剩下只出现一次的那个。**O(n) 时间、O(1) 空间**，比用哈希表（O(n) 空间）更优。变体：找两个只出现一次的数（先全异或得两数异或值，再用 lowbit 分组）、找缺失的数字（下标和值异或）。

异或还可用于：交换两数（不用临时变量）、找两数差异位、加密。

## 四、位运算应用：状态压缩

**状态压缩**：用一个整数的二进制位表示一个集合的状态（每位 1/0 表示某元素选/不选），高效枚举子集、做状压 DP（[16](./16-精通-经典DP专题.md)）。

```go
// 枚举一个集合 {0,1,...,n-1} 的所有子集
for mask := 0; mask < (1 << n); mask++ { // mask 的每一位代表一个元素
    for i := 0; i < n; i++ {
        if mask&(1<<i) != 0 { // 第 i 位为 1 → 元素 i 在子集中
            // 元素 i 被选中
        }
    }
}
```

- `1 << n` = 2ⁿ（n 个元素的所有子集数）。
- `mask & (1<<i)` 判断第 i 个元素在不在集合里。
- `mask | (1<<i)` 加入元素 i，`mask & ^(1<<i)` 移除。

状态压缩用于 n 较小（≤ 20）的集合问题：旅行商问题（TSP）、状压 DP、子集枚举（[08 回溯](./08-精通-递归回溯与DFS.md) 的位运算版）。用整数表示集合，O(1) 增删查，比用 set 高效。

## 五、数学：快速幂

**快速幂**：求 aⁿ，O(log n)（朴素连乘是 O(n)）。原理：`aⁿ = (a^(n/2))²`，每次指数减半（分治，[09](./09-精通-分治与归并思想.md)）。

```go
// 快速幂：a^n（迭代版，二进制思想）
func quickPow(a, n int) int {
    result := 1
    for n > 0 {
        if n&1 == 1 { // 当前二进制位为 1
            result *= a // 累乘
        }
        a *= a   // a 翻倍（a^1 → a^2 → a^4 ...）
        n >>= 1  // 指数右移
    }
    return result
}
```

原理：把指数 n 看成二进制，`a^n = a^(b_k·2^k + ... + b_0·2^0)`，对每个为 1 的二进制位累乘对应的 `a^(2^i)`。每次 a 自乘（得 a²、a⁴、a⁸…），n 右移检查每一位。O(log n)。**带取模的快速幂**（`(a*b) % m`）是密码学、大数运算的基础。矩阵快速幂可 O(log n) 求斐波那契等线性递推。

## 六、数学：GCD 与质数

**最大公约数（GCD）—— 欧几里得算法（辗转相除）**：

```go
// gcd(a, b) = gcd(b, a%b)，直到 b 为 0
func gcd(a, b int) int {
    for b != 0 {
        a, b = b, a%b
    }
    return a
}
// 最小公倍数：lcm(a,b) = a/gcd(a,b)*b
func lcm(a, b int) int {
    return a / gcd(a, b) * b
}
```

**质数筛（埃拉托斯特尼筛）—— 求 [2, n] 内所有质数，O(n log log n)**：

```go
// 埃氏筛：标记每个质数的倍数为合数
func countPrimes(n int) int {
    isComposite := make([]bool, n)
    count := 0
    for i := 2; i < n; i++ {
        if !isComposite[i] { // i 是质数
            count++
            for j := i * i; j < n; j += i { // 把 i 的倍数标记为合数
                isComposite[j] = true
            }
        }
    }
    return count
}
```

埃氏筛思想：**从小到大，每遇到一个质数就把它的所有倍数划掉**，没被划掉的就是质数。从 `i*i` 开始划（更小的倍数已被更小质数划过）。线性筛（欧拉筛）能优化到 O(n)。

## 陷阱清单

- **Go 取反用 `~`**：Go 没有 `~`，按位取反是一元 `^x`。
- **位运算优先级**：`&`、`|`、`^` 优先级低于比较运算，`x & 1 == 0` 要加括号 `(x & 1) == 0`（Go 中 `&` 比 `==` 低）。
- **左移溢出**：`1 << n` 当 n 大时溢出，注意类型（int64）和范围。
- **异或找数的前提**：只出现一次的数靠"其余都成对"，条件不满足（如出现三次）要用别的方法（按位计数）。
- **快速幂不取模溢出**：大数快速幂要边乘边取模，否则溢出。
- **质数筛从 i 开始划**：应从 `i*i` 开始（更小倍数已划），从 2*i 开始会重复但不算错（效率低）。
- **GCD 边界**：gcd(a, 0) = a，递归/迭代终止条件是 b==0。
- **负数取模**：不同语言负数取模符号不同，Go 中 `-7 % 3 = -1`，注意。

- **位运算是"小技巧"高频点**：异或找数、统计 1 的个数、判 2 的幂、状态压缩是常考的巧妙题，能 O(1)/O(n) 空间最优解。

## 练习题

1. 解释 `x & (x-1)` 和 `x & (-x)` 这两个位运算技巧的作用。

<details><summary>参考答案</summary>

①**`x & (x-1)`——消去（清除）x 二进制中最低位的那个 1**。原理：x-1 会把 x 的最低位 1 变成 0、并把它后面所有的 0 变成 1（借位），其余高位不变；再和 x 做按位与，就恰好把那个最低位的 1 清除掉、而其他位保持不变。例如 x = 12 (1100)，x-1 = 11 (1011)，x & (x-1) = 1000 (8)，最低位的 1 被消去了。**用途**：①**统计二进制中 1 的个数**（Brian Kernighan 算法）——不断执行 `x &= x-1` 直到 x 变成 0，执行的次数就是 1 的个数（每次消掉一个 1），比逐位检查更快（只循环"1 的个数"次）；②**判断是否是 2 的幂**——一个正数是 2 的幂当且仅当它的二进制中只有一个 1，所以 `x > 0 && (x & (x-1)) == 0` 为真则是 2 的幂（消去唯一的 1 后变成 0）；③判断是否只有一个 1、清除最低位 1 等。②**`x & (-x)`——取出（保留）x 二进制中最低位的那个 1（其余位清零），通常称为 lowbit**。原理：在补码表示下，-x = (~x) + 1（按位取反再加 1），这会使得从最低位 1 开始的部分与 x 相同、而更高位相反，两者按位与就只保留了最低位的那个 1。例如 x = 12 (1100)，-x 的补码是 ...0100，x & (-x) = 0100 (4)，即最低位 1 所代表的值。**用途**：①**树状数组（Binary Indexed Tree / Fenwick Tree）**——lowbit 是树状数组求和、更新时确定管辖区间和跳转父节点的核心操作；②**枚举子集、状态压缩**中定位/取出某一位；③求最低位 1 代表的数值。这两个技巧都是利用补码和借位的性质，用 O(1) 的位运算完成"消最低位 1"和"取最低位 1"，是位运算题和树状数组的基础工具，建议记牢。

</details>

2. 数组中除一个数只出现一次、其余都出现两次，如何 O(1) 空间找出那个数？为什么用异或？

<details><summary>参考答案</summary>

用**异或（XOR）**：把数组中所有数字依次异或起来，最终的结果就是那个只出现一次的数字。代码就是 `res := 0; for _, x := range nums { res ^= x }; return res`。时间 O(n)、**空间 O(1)**（只用一个变量）。**为什么用异或、为什么正确**：异或运算有三个关键性质——①**`a ^ a = 0`**（任何数和它自己异或都等于 0）；②**`a ^ 0 = a`**（任何数和 0 异或还是它自己）；③异或满足**交换律和结合律**（即异或的顺序、分组都不影响最终结果）。基于这些性质：当我们把数组里所有数全部异或在一起时，由于异或满足交换律和结合律，可以把相同的数两两配对地放在一起异或——那些**出现两次的数字，每一对都是 `a ^ a = 0`，互相抵消变成 0**；而那个只出现一次的数字没有配对，最后剩下 `0 ^ 0 ^ ... ^ 唯一的数 = 唯一的数`。所以全部异或的结果正好就是只出现一次的那个数。这个方法的优势：相比用**哈希表**统计每个数出现次数（O(n) 时间但需要 O(n) 额外空间），异或法只需 O(1) 空间、O(n) 时间，更优；它巧妙利用了异或"成对抵消"的特性，无需额外存储。**变体**：①如果有**两个**只出现一次的数（其余成对）——先把所有数异或得到这两个数的异或值 xor_sum（它一定不为 0），用 lowbit `xor_sum & (-xor_sum)` 找到这两个数**某一个不同的二进制位**，按这一位是 0 还是 1 把所有数分成两组，每组内各自全异或，就分别得到这两个数；②如果某个数出现**三次**（其余成对）则异或法失效（三次异或不为 0），要改用"统计每一位上 1 出现的次数对 3 取余"等按位计数的方法。但对"一个出现一次、其余出现两次"的经典情形，全部异或是最优雅高效的解法。

</details>

3. 快速幂如何在 O(log n) 内计算 aⁿ？说明其原理。

<details><summary>参考答案</summary>

朴素计算 aⁿ 是把 a 连乘 n 次，O(n)。**快速幂**利用"指数可以折半"的分治思想，把复杂度降到 **O(log n)**。**原理**：核心恒等式是 **aⁿ = (a^(n/2))²**（当 n 为偶数）或 **aⁿ = a × (a^((n-1)/2))²**（当 n 为奇数）——也就是说，求 aⁿ 可以先求出 a^(n/2)、再平方，而不是老老实实乘 n 次。每做一次"折半"，指数就减小一半，所以只需约 log₂n 次就能算到底，O(log n)。**从二进制角度理解（迭代实现）**：把指数 n 写成二进制，n = b_k·2^k + ... + b_1·2 + b_0（b_i 是 0 或 1），那么 a^n = a^(∑ b_i·2^i) = ∏(a^(2^i))，其中只有 b_i=1 的那些项参与连乘。于是迭代做法是：维护一个底数 base（初始为 a）和结果 result（初始为 1），从低位到高位扫描 n 的每一个二进制位——每一步先看 n 的当前最低位（`n & 1`）：如果是 1，就把当前的 base 乘进 result（`result *= base`）；然后把 **base 自乘**（`base *= base`，使它依次变成 a^1 → a^2 → a^4 → a^8 …，对应 2 的各次幂）、并把 **n 右移一位**（`n >>= 1`，处理下一个二进制位）；直到 n 变为 0。这样每个二进制位处理一次、共 log n 位，每次是常数次乘法，总 O(log n)。例如求 a^13，13 = 1101₂，结果 = a^8 × a^4 × a^1（对应二进制的第 3、2、0 位为 1）。**实际应用**常配合**取模**——"快速幂取模"在每步乘法后都对结果取模（`result = result * base % mod`、`base = base * base % mod`），用于大数幂取模（密码学如 RSA、哈希、组合数取模等），避免数值溢出。此外，把"乘法"换成"矩阵乘法"就是**矩阵快速幂**，可在 O(log n) 内求斐波那契等线性递推的第 n 项。快速幂是分治/二进制思想在数学计算中的经典应用。

</details>

4. 欧几里得算法（辗转相除法）求最大公约数的原理是什么？

<details><summary>参考答案</summary>

**欧几里得算法（辗转相除法）** 求两个数的最大公约数（GCD），基于一个关键定理：**gcd(a, b) = gcd(b, a mod b)**（其中 a mod b 是 a 除以 b 的余数），不断用这个等式把问题规模缩小，直到余数为 0。具体过程：求 gcd(a, b) 时，用较大数除以较小数得到余数，然后把"较小数"和"余数"作为新的一对数继续求 gcd，重复这个"除、取余、替换"的过程，**当余数变为 0 时，此时的除数（最后一个非零余数）就是最大公约数**。迭代写法：`for b != 0 { a, b = b, a % b }; return a`——每次用 (b, a%b) 替换 (a, b)，直到 b 为 0，返回 a。例如 gcd(48, 36)：48 mod 36 = 12 → gcd(36, 12)；36 mod 12 = 0 → gcd(12, 0) = 12，所以最大公约数是 12。**原理（为什么 gcd(a,b) = gcd(b, a mod b)）**：设 a = q·b + r（q 是商，r = a mod b 是余数）。要证明 a 和 b 的公约数集合与 b 和 r 的公约数集合相同：①任何能同时整除 a 和 b 的数 d，由 r = a - q·b 可知 d 也能整除 r（整除 a 和 b 的线性组合），所以 d 也是 b 和 r 的公约数；②反过来，任何能同时整除 b 和 r 的数 d，由 a = q·b + r 可知 d 也能整除 a，所以 d 也是 a 和 b 的公约数。既然两对数的公约数集合完全相同，它们的**最大**公约数自然也相同，即 gcd(a, b) = gcd(b, r) = gcd(b, a mod b)。每一步用取余把数变小（r < b），所以很快收敛（实际上收敛很快，复杂度约 O(log(min(a,b)))）。**应用**：求最大公约数、**最小公倍数**（lcm(a,b) = a / gcd(a,b) × b，先除后乘防溢出）、分数化简、判断互质、扩展欧几里得（求解 ax+by=gcd 及模逆元，用于密码学）等。辗转相除法简单高效，是数论的基础算法。

</details>

5. 埃拉托斯特尼筛法如何求一定范围内的所有质数？复杂度是多少？

<details><summary>参考答案</summary>

**埃拉托斯特尼筛法（埃氏筛）** 用于求出区间 [2, n] 内的所有质数，核心思想是"**从小到大，每找到一个质数，就把它的所有倍数标记为合数（划掉），最后没有被划掉的就是质数**"。具体过程：①准备一个布尔数组（如 isComposite[]，初始都为 false，表示"暂未判定为合数"），下标代表数字；②从 2 开始遍历到 n：如果当前数 i **没有被标记为合数**（说明它不是任何更小数的倍数，因此它是质数），就把它记为质数，并把它的所有倍数 2i、3i、4i……（在范围内的）都**标记为合数**；如果 i 已经被标记为合数，就跳过。③遍历结束后，所有没被标记的数就是质数。**优化细节**：①标记倍数时**从 i×i 开始**（而不是从 2i 开始），因为比 i×i 小的 i 的倍数（如 2i、3i、…、(i-1)i）在处理更小的质数因子时就已经被标记过了（例如 2i 在筛 2 时已划掉、3i 在筛 3 时已划掉），从 i×i 开始避免重复标记、提高效率；②外层循环只需到 √n（因为大于 √n 的数如果是合数，其较小因子必定 ≤ √n、早已被标记，所以 √n 之后不会再有新的质数倍数需要从它开始筛——不过统计质数个数时外层仍要遍历到 n 来判断每个数是否被标记）。**复杂度**：时间复杂度约为 **O(n log log n)**（接近线性，log log n 增长极慢，可近似看作线性），这来自于对每个质数 p 标记其倍数的操作次数之和（调和级数式求和的结果）；空间复杂度 O(n)（标记数组）。**进阶**：埃氏筛会重复标记某些合数（一个合数可能被它的多个质因子各标记一次，如 12 被 2 和 3 都标记），**线性筛（欧拉筛）** 通过保证"每个合数只被它的最小质因子标记一次"把复杂度优化到严格的 **O(n)**，但实现稍复杂。对大多数面试场景，埃氏筛的 O(n log log n) 已足够高效、且实现简单，是求质数的标准方法（如 LeetCode "计数质数"）。

</details>

6. 什么是状态压缩？它适合解决什么样的问题？

<details><summary>参考答案</summary>

**状态压缩**是指用**一个整数的二进制位来表示一个集合（或一组布尔状态）**的技巧：把集合中"每个元素是否被选中/某个位置是否被占用"等用整数的某一个二进制位（0 或 1）来表示，于是整个集合的状态就被"压缩"成了一个整数。例如对一个有 n 个元素的集合，用一个 n 位的整数 mask 表示其子集——mask 的第 i 位为 1 表示元素 i 在子集中、为 0 表示不在。这样就能用整数的位运算高效地操作集合：`mask & (1<<i)` 判断元素 i 是否在集合中（取第 i 位）、`mask | (1<<i)` 加入元素 i、`mask & ^(1<<i)` 移除元素 i、`1<<n` 表示全集大小（2ⁿ 个子集）、遍历 `for mask := 0; mask < (1<<n); mask++` 即可枚举所有 2ⁿ 个子集。用整数表示集合的好处是：判断/增删元素都是 O(1) 的位运算、可以把"集合"作为数组下标或 DP 的状态（哈希），比用真正的 set 数据结构更快更省。**适合解决的问题**：①**状态压缩 DP（状压 DP）**——当问题的"状态"是一个**规模较小的集合**（元素个数 n 通常 ≤ 20，因为状态总数是 2ⁿ，n 太大会爆炸），且需要把"已选/已访问的元素集合"作为 DP 的状态维度时，就用一个整数 mask 表示这个集合作为 dp 的下标。典型如**旅行商问题（TSP，dp[mask][i] 表示已访问城市集合为 mask、当前在城市 i 的最短路径）**、棋盘/网格覆盖问题（如铺砖、放置互不攻击的棋子）、集合划分、压缩状态的图论问题等。②**子集枚举**——用位运算枚举一个小集合的所有子集（替代回溯，见 08），以及枚举某个子集的所有子集（更高级技巧）。③需要把"一组布尔标志"紧凑表示和快速操作的场景（如权限位、布隆过滤器思想、棋盘状态）。**关键限制**：状态压缩适用于**集合元素个数较小**（一般 n ≤ 20，2²⁰ ≈ 100万 状态可接受；n 再大状态数指数爆炸就不可行）的情况。一句话：当问题状态是一个小集合、需要高效地表示和枚举集合状态时（尤其是状压 DP 和小集合的子集枚举），就用一个整数的二进制位来压缩表示集合、用位运算操作它。

</details>
